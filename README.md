# Assistente de Políticas de RH: Rota Sul Logística

Assistente web que responde perguntas de funcionários com base apenas nas políticas oficiais de RH,
sempre citando a política e a seção de origem.

> **Aviso:** a Rota Sul Logística Ltda. é uma empresa fictícia. Este é um caso simulado, criado como
> projeto de portfólio de engenharia de IA. Pessoas, políticas e dados são inventados.
